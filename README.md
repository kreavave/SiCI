# SiCI — Sistema de Cotización de Infracciones

**SiCI** es una solución de software desarrollada por **KREAVAVE**, diseñada específicamente para la gestión, sistematización y cotización automatizada de actas e infracciones de tránsito en **Juzgados de Faltas Municipales y Provinciales**.

---

## 📌 Características Principales

* **Cotización Automatizada:** Cálculo preciso de montos de infracciones según Unidades Fijas (UF), ordenanzas y normativas vigentes.
* **Gestión Judicial Auxiliar:** Herramienta ágil diseñada para jueces, operadores y secretarios de Juzgados de Faltas.
* **Validación Remota de Licencias:** Sistema de autenticación de seguridad encriptada vía servidor central.
* **Integridad y Control:** Control de acceso, registro de actividades y protección del entorno informático.

---

## 💻 Requisitos del Sistema

* **Sistema Operativo:** Windows 10 / Windows 11 (64-bit).
* **Conexión a Internet:** **Obligatoria** para el inicio de sesión, validación periódica del código de licencia y verificación de integridad.
* **Entorno:** .NET Framework 4.8 o superior / acceso a la red local o remota del Juzgado.
